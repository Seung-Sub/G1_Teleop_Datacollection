# Inspire RH56E2 / FTP (RH56DFTP) Dexterous Hand — 상세 스펙 & 제어 레퍼런스

> 대상: Unitree G1에 장착되는 Inspire 5지 dexterous hand.
> 모델 정리: **RH56E2 = FTP 시리즈 = RH56DFTP** (Unitree 측 부품명은 **RH56DFQ-2L / RH56DFQ-2R**).
> 촉각 구성 2종: **T1(저항식, 17점, 0–30N)**, **T2(정전식, 5점, 0–20N)**.
> 핵심: 모터 과부하 보호용 **전류제한(CURRENT_LIMIT)**, **힘제어(FORCE_SET)**, 그리고 **전류/온도/상태/에러 피드백**이 펌웨어에 내장되어 있음 → 단순 위치제어 외에 안전 제어가 가능.

| 자유도(DOF) | 6 | 액추에이터 6개 |
| 관절 수 | 12 | |

| 항목 | 값 |
|---|---|
| 엄지 지문 힘 | 30 N |

> ⚠️ **주의 — 두 가지 스펙이 섞여 있음.** 위 표는 E2 제품 마케팅 공시값(28/30N, 0.05N).
> 반면 펌웨어/레지스터 단위와 함께 쓰이는 RH56 시리즈 **매뉴얼**의 일반 성능표는 더 보수적입니다:
> - 힘 센서 분해능: 0.5 N
> - 4지 그립힘: DF형 10 N / BF형 4 N, 엄지: DF형 15 N / BF형 6 N

>
> E2/FTP는 매뉴얼 기준 "DF(대력)" 계열의 강화판으로 보면 됩니다. **제어 펌웨어 레지스터 정의·단위·범위는 RH56 시리즈 공통 매뉴얼을 그대로 따릅니다.**

## 2. DOF 인덱스 매핑 (레지스터 m = 0~5)

| m | 손가락 / 동작 |
|---|---|
| 0 | 새끼손가락(little) |
| 1 | 약지(ring) |
| 2 | 중지(middle) |
| 3 | 검지(index) |
| 4 | 엄지 굴곡(thumb bending) |
| 5 | 엄지 회전(thumb rotation) |

> ⚠️ Unitree SDK / ROS 드라이버는 배열 순서를 **역순([엄지회전, 엄지굴곡, 검지, 중지, 약지, 새끼] 등)** 으로 쓰는 경우가 있으니, 실제 사용하는 드라이버의 인덱스 정의를 반드시 확인하고 매핑하세요.

## 3. 통신 프로토콜 개요

- **RS485 native**: 8N1, 기본 baud **115200**(설정값 0=115200, 1=57600, 2=19200).
  - 프레임 헤더: 읽기 `0xEB 0x90`, 응답 `0x90 0xEB`. 읽기 플래그 `0x11`, 쓰기 플래그 `0x12`.
  - Checksum = 헤더 제외 앞 데이터 합의 하위 바이트.
- **Modbus RTU/TCP**: 0x03(holding register 읽기), 0x06(단일 레지스터 쓰기), 0x10(다중 레지스터 쓰기) 지원. (Unitree/오픈소스 드라이버 대부분 Modbus RTU 사용)
- 한 RS485 버스에 변환회로로 최대 254개 핸드 병렬 연결 가능 (HAND_ID로 구분).

## 4. 레지스터 맵 (제어 핵심) — RH56 시리즈 공통

> 모든 (m) 그룹은 DOF 6개 = 6×short(12 byte). short는 little-endian.

### 4.1 설정/관리 레지스터

| 주소(dec/hex) | 이름 | 길이 | R/W | 설명 |
|---|---|---|---|---|
| 1000 / 0x03E8 | HAND_ID | 1B | W/R | ID 1–254, 저장가능 |
| 1002 / 0x03EA | REDU_RATIO | 1B | W/R | baud 0/1/2 |
| 1004 / 0x03EC | CLEAR_ERROR | 1B | W/R | 1 쓰면 클리어 가능 에러 해제(과온은 불가) |
| 1005 / 0x03ED | SAVE | 1B | W/R | 1 쓰면 Flash 저장 |
| 1006 / 0x03EE | RESET_PARA | 1B | W/R | 공장초기화 |
| 1009 / 0x03F1 | GESTURE_FORCE_CLB | 1B | W/R | 힘센서 캘리브레이션(6초, 무부하 필수) |

### 4.2 ★과부하 보호 핵심 레지스터★

| 주소(dec) | 이름 | 단위 | 범위 | 저장 | 설명 |
|---|---|---|---|---|---|
| 1020–1031 | **CURRENT_LIMIT(m)** | mA | 0–1500 | ✔ | **DOF별 전류 보호값. 초과 시 손가락 정지 + STATUS=5로 표시.** 과부하 방지의 1차 방어선 |
| 1032–1043 | DEFAULT_SPEED_SET(m) | 무차원 | 0–1000 | ✔ | 전원 인가 시 기본 속도 |
| 1044–1055 | DEFAULT_FORCE_SET(m) | g | 0–1000 (엄지굴곡 0–1500) | ✔ | 전원 인가 시 기본 힘제어 임계값 |

### 4.3 실시간 제어 명령(쓰기)

| 주소(dec) | 이름 | 단위 | 범위 | 저장 | 설명 |
|---|---|---|---|---|---|
| 1474–1485 | POS_SET(m) | 무차원 | 0–2000, −1 | �’ | 액추에이터 스트로크. 0=개방(최대각), 2000=굴곡(최소각), −1=동작안함. *각도 지정 용도로는 비권장* |
| 1486–1497 | **ANGLE_SET(m)** | 무차원 | 0–1000, −1 | ✔ | **권장 위치 명령.** 1000=개방, 0=굴곡, −1=무동작 |
| 1498–1509 | **FORCE_SET(m)** | g | 0–1000 | ✔ | **힘제어 임계값. FORCE_ACT가 이 값 도달 시 손가락 정지(STATUS=3).** 과그립 방지 핵심 |
| 1522–1533 | SPEED_SET(m) | 무차원 | 0–1000 | ✔ | 속도. 1000 = 무부하 full travel ≈ 800ms |

### 4.4 상태 피드백(읽기 전용)

| 주소(dec) | 이름 | 단위 | 범위 | 설명 |
|---|---|---|---|---|
| 1472 / 0x05C0 | VOLTAGE | — | — | 시스템 전압(1 short) |
| 1534–1545 | POS_ACT(m) | 무차원 | 0–2000 | 실제 액추에이터 위치 |
| 1546–1557 | ANGLE_ACT(m) | 무차원 | 0–1000 | 실제 각도 |
| 1582–1593 | **FORCE_ACT(m)** | g | 0–1000 | 실제 손가락 작용 힘 |
| 1594–1605 | **CURRENT(m)** | mA | 0–1000 | DOF별 실제 전류 |
| 1606–1611 | **ERROR(m)** | bit | 1B/DOF | 에러 코드(아래) |
| 1612–1617 | **STATUS(m)** | code | 1B/DOF | 상태 코드(아래) |
| 1618–1623 | **TEMP(m)** | ℃ | 0–100 | DOF별 액추에이터 온도 |

### 4.5 ERROR(m) 비트 정의

| 비트 | 의미 |
|---|---|
| Bit0 | 락드로터(locked-rotor / 구속) |
| Bit1 | 과온(over-temperature) — *자동 클리어만 가능, 수동 클리어 불가* |
| Bit2 | 과전류(over-current) |
| Bit3 | 모터 비정상 동작 |
| Bit4 | 통신 에러 |

### 4.6 STATUS(m) 코드 정의

| 코드 | 의미 |
|---|---|
| 0 | 펴는 중(unclenching) |
| 1 | 쥐는 중(grasping) |
| 2 | 목표 위치 도달 후 정지 |
| 3 | 설정 힘제어값 도달 후 정지 |
| 5 | **전류 보호로 정지** |
| 6 | **락드로터로 정지** |
| 7 | **액추에이터 고장으로 정지** |

### 4.7 동작 시퀀스 (옵션)

2000~2324 영역에 8스텝짜리 동작 시퀀스(각도/속도/힘/지연) 최대 40세트 Flash 저장·재생 가능. 자율 제어 시에는 보통 미사용.

## 5. 과부하 안전 제어 설계 가이드 (요약)

핵심 통찰: **이 핸드는 "토크 제어 가능한 모터 6개"가 아니라, 펌웨어가 위치/힘/전류 보호를 알아서 해주는 폐루프 액추에이터입니다.** 따라서 컨트롤러는 "raw 위치를 막 밀어넣기"보다 다음을 조합하면 모터를 거의 태우지 않습니다.

1. **CURRENT_LIMIT(m) 설정 (1차 하드 방어).** DOF별로 보수적 값(예: 정상 그립 전류의 1.2~1.5배)으로 잡으면 초과 시 펌웨어가 즉시 정지(STATUS=5). 한 번 SAVE하면 전원 사이클 후에도 유지.
2. **FORCE_SET(m) 설정 (그립 과압 방지).** 위치 목표를 끝까지(0=굴곡) 주더라도, FORCE_ACT가 임계값에 닿으면 멈춤(STATUS=3). 물체 경도에 따라 임계값만 바꾸면 됨 → "위치제어로 끝까지 밀어 stall" 상황을 원천 차단.
3. **SPEED_SET(m) 적당히 낮추기.** 충돌·접촉 시 충격 전류 피크를 줄임.
4. **고속 모니터링 루프**: CURRENT(m), TEMP(m), STATUS(m), ERROR(m)를 주기적으로 폴링.
   - TEMP가 임계(예: 70℃)에 근접하면 듀티 다운/휴지.
   - STATUS가 5/6/7이거나 ERROR≠0이면 해당 DOF 명령 중단 → CLEAR_ERROR.
   - 과온(Bit1)은 수동 클리어 불가, 온도 떨어질 때까지 대기.
5. **위치 명령은 ANGLE_SET(m)** 사용(POS_SET 비권장). −1로 특정 DOF를 "유지/무동작" 시킬 수 있어 부분 제어에 유용.

> 전형적 패턴: "목표 각도 = 0(완전 굴곡) 또는 물체 예상 위치"로 ANGLE_SET을 주되, FORCE_SET으로 그립력 상한을 걸고, CURRENT_LIMIT으로 절대 하드 리밋을 건 다음, STATUS로 정지 사유(위치 도달=2 / 힘 도달=3 / 보호=5)를 구분해 상위 로직에 전달.

## 6. Unitree G1 통합 메모

- Unitree G1 EDU의 Inspire 핸드는 **RS485 / Modbus RTU**로 연결됨(부품명 RH56DFQ-2L/2R, FTP=17점 촉각).
- Unitree 측 SDK / ROS 드라이버, 그리고 커뮤니티 라이브러리(예: GitHub의 RH56 Modbus RTU Python 라이브러리들)가 위 레지스터 맵을 그대로 래핑함.
- 드라이버마다 **DOF 배열 순서**와 **각도 정규화(0–1000 vs 0–1.0)** 정의가 다르므로, 직접 확인 후 매핑할 것.
- 촉각(17점) 데이터는 기본 RH56 매뉴얼 범위 밖의 확장 프로토콜이므로, FTP 전용 촉각 프로토콜 문서/드라이버를 별도로 확보해야 함(레지스터/패킷 정의가 본 매뉴얼에 미포함).
